💡 Problem Description

This program takes an integer input from the user and prints its digits from left to right, each on a new line.

📌 Program Flow:
	1.	Read an integer from the user.
	2.	Reverse the number first (e.g., 123 → 321).
	3.	Then print the digits of the reversed number from last to first, so they appear in the original left-to-right order.

🔍 Example:
	•	Input: 573
	•	Output:

5
7
3



🎯 The goal is to display each digit of the number line by line, in the same order they appear visually (left to right), even if using mathematical reversal internally.
