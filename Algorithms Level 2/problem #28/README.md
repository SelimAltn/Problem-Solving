### 💡 Problem Description

This program prompts the user to enter an array size and generates a **first array (Arry)** filled with random numbers between 1 and 100. The contents of this array are then **manually copied into a second array (Arry2)**. Both arrays are printed separately.

📌 **Program Flow:**

* The user enters the array size (between 1–100).
* The first array is filled with random values using the `rand()` function.
* The first array is printed to the screen.
* All elements are manually copied to the `Arry2` array.
* The second array is also printed to show that the copy operation was successful.

---

### ✅ Sample Output

```
enter a Arry size ? 
5
ARRY 1 : [37 , 85 , 62 , 13 , 90]
ARRY 2 : [37 , 85 , 62 , 13 , 90]
```

> Note: The numbers in the array may vary on each run.

---

### 🎯 Objective

To teach how to **manually copy** the contents of one array to another. This helps build foundational practice in working with arrays, data transfer, and memory-level operations.
