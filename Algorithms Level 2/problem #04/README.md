### 💡 Problem Description

This program prompts the user to enter a number and:

1. Checks whether the entered number is a **perfect number**,
2. Also lists **all perfect numbers from 1 up to the entered number**.

🔹 **Definition of a Perfect Number:**
A number is considered a **perfect number** if the **sum of its positive divisors excluding itself** equals the number.
For example:

* 6 → 1 + 2 + 3 = 6
* 28 → 1 + 2 + 4 + 7 + 14 = 28

The goal of the program is to both check whether a single number is perfect and to list all perfect numbers up to that number.
