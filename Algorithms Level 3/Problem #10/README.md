
### 💡 Problem Description

This program generates a 3x3 matrix filled with random numbers and calculates the sum of all its elements.

---

### 📌 Program Flow

1. A 3x3 matrix is filled with random integers between 1 and 9.
2. The matrix is printed to the console.
3. A loop calculates the total sum of all values in the matrix.
4. The result is displayed.

---

### ✅ Sample Output

```
Matrix 1 : 
| 03  07  02  |
| 09  01  06  |
| 04  08  05  |
Sum of Matrix1 : 45
```

---

### 🎯 Goal

To practice 2D array traversal and element-wise accumulation using nested loops.
