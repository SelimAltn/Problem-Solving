

## 🔍 Search for a Number in a Matrix

### 💡 Problem Description

This program checks whether a specific number exists in a 3x3 matrix filled with random values. Two approaches are used to perform this check.

### 📌 Program Behavior

* A 3x3 matrix is filled with random integers between 1 and 9.
* The user is prompted to enter a number.
* The program then checks if the number is present in the matrix using:

  1. A count-based method.
  2. A faster short-circuiting search method.
* The results of both checks are printed.
