### 📝 README: Vowel Detection and Extraction from Strings

💡 **Problem Description**
This program allows users to work with vowels in a given string. It includes functionality to:

* Check if a character is a vowel.
* Count the number of vowels in a string.
* Print all vowels present in the string.

📌 **Program Features**

* `IsVowelChar(char)`: Checks whether a character is a vowel (optimized version).
* `IsVowelChar(char, bool Slow)`: An alternative version using an array of vowels (slower).
* `CountVowels(string)`: Returns the number of vowels in the given string.
* `PrintAllVowelsInString(string)`: Outputs all vowels found in the string, separated by spaces.
* User inputs both a string and a character to test against these functionalities.

✅ **Example Output**

```
Please Enter Your String ? Hello Universe
Please Enter Your Char ? e
Yes Is Letter 
Yes Is Letter 
Number Of Vowels is : 6
Vowels In String are : e    o    U    i    e    e    
```

🎯 **Purpose**
This exercise enhances understanding of:

* Character manipulation in C++
* String traversal
* Function overloading and utility design for performance comparison (slow vs fast check)
* Basic text processing logic
