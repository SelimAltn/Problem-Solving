## 🧠 Capitalize First Letter of Each Word

This program takes a sentence and capitalizes the **first letter of each word**, leaving the rest of the characters unchanged.

---

### 💡 Problem Description

Given a string containing multiple words, convert it so that the **first letter of each word is uppercase**, and all other letters remain as they are.

---

### 📌 How the Program Works

* It loops through each character in the string.
* If a character is not a space and it is the first character of a word, it is converted to uppercase using `toupper`.
* The result is returned as a new formatted string.

---

### ✅ Sample Output

```
mohammed saqer abu-Hahdoud

String after conversion:
Mohammed Saqer Abu-Hahdoud
```

---

### 🎯 Goal

To practice string manipulation, character checks, and ASCII conversion functions in C++.
