
### 💡 Problem Description

This program generates a 3x3 matrix with random values and extracts both the middle row and the middle column of the matrix.

---

### 📌 Program Flow

1. A 3x3 matrix is filled with random integers from 1 to 9.
2. The middle row (second row) is extracted and stored in a separate array.
3. The middle column (second column) is extracted and stored in another array.
4. The matrix and the extracted row and column are printed.

---

### ✅ Sample Output

```
Matrix  :

|  03  06  01  |
|  02  05  08  |
|  09  04  07  |

Middle Row Of matrix 1 is :
 02  05  08

Middle Col Of matrix 1 is :
 06  05  04
```

---

### 🎯 Goal

To understand how to access and extract specific rows and columns from a 2D array, focusing on middle row/column operations in fixed-size matrices.
