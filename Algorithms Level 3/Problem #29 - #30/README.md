## 🔡 Count Letters in a String

This program analyzes a user-provided string and performs character-based statistics, including:

* Counting the total number of **uppercase** and **lowercase** letters.
* Counting the **occurrences** of a specific character (case-insensitive).
* Displaying the string’s **length**.

---

### 💡 Problem Description

Given a string input by the user, the program counts:

* How many letters are uppercase.
* How many letters are lowercase.
* How many times a specific letter appears in the string.

Character counting is **case-insensitive** when checking for a specific letter.

---

### 📌 How the Program Works

* The user enters a full string.
* Then, the user is asked to enter a single character.
* The program prints the string's length and the character statistics.

---

### ✅ Sample Output

```
Please Enter Your String ? 
Hello World!

String Length is : 12
Capital Letters Count = 2
Small  Letters Count = 8

Please Enter Your Char ? 
l
Latter 'l' Count : 3
```

---

### 🎯 Goal

To practice working with character classification (`islower`, `isupper`) and counting logic using loops and conditionals.
