
## 🔗 Find Intersected Numbers Between Two Matrices

### 💡 Problem Description

This program identifies the numbers that are common (intersected) between two randomly generated 3x3 matrices.

### 📌 Program Behavior

* Two 3x3 matrices are filled with random numbers from 1 to 9.
* A comparison is made to find numbers that exist in both matrices.
* The intersected numbers are stored in an array and printed.

### ✅ Example Output

```
Matrix 1 : 
|  4   6   2  |
|  8   1   5  |
|  3   7   9  |


Matrix 2 : 
|  7   2   1  |
|  6   4   0  |
|  8   3   9  |


Intercsected Number are : 
 07   02   01   06   04   08   03   09  
```

### 🎯 Purpose

To practice:

* Nested loops with matrix data.
* Detecting shared elements across 2D arrays.
* Using helper functions and efficient element lookup.
