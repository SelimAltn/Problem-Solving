### 💡 Problem Description

This program generates two 3x3 matrices with random values and performs element-wise multiplication.

---

### 📌 Program Flow

1. Two matrices are filled with random numbers between 1 and 9.
2. Each element of the first matrix is multiplied by the corresponding element in the second matrix.
3. The resulting matrix is printed.

---

### ✅ Sample Output

```
Matrix 1 :

|   4   1   6   |
|   2   9   8   |
|   7   3   5   |

Matrix 2 :

|   5   2   4   |
|   3   6   7   |
|   1   8   2   |

Result :

|  20   2  24   |
|   6  54  56   |
|   7  24  10   |
```

---

### 🎯 Goal

Understand element-wise matrix operations and practice nested loop logic using fixed-size 2D arrays.
