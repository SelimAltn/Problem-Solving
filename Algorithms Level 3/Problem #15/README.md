
## 🔢 Count Occurrences of a Number in a Matrix

### 💡 Problem Description

This program counts how many times a specific number appears in a 3x3 matrix filled with random numbers between 1 and 9.

### 📌 Program Behavior

* Generates and displays a 3x3 matrix of random integers.
* Prompts the user to enter a number.
* Counts and displays how many times that number appears in the matrix.

### ✅ Example Output

```
| 07  04  03  |
| 01  07  09  |
| 07  05  02  |

Enter the Number to Count in matrix ?
7
Number 7 Count in matrix is 3
```

### 🎯 Purpose

To practice:

* Matrix traversal
* Input validation
* Counting specific values within a 2D array.
