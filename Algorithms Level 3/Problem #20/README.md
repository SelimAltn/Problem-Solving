## 🧩 Palindrome Matrix Checker

This program checks whether a given matrix is a **palindrome matrix**.

### 💡 Problem Description

A **palindrome matrix** in this context means that **each row is a palindrome**, i.e., the row reads the same forwards and backwards.

For example:

```
[1 2 1]
[5 6 5]
[7 8 7]
```

Each row is symmetric around its center, making the matrix a **row-wise palindrome matrix**.

### 📌 How It Works

* The matrix is filled manually or randomly.
* The function `IsPalindromeMatrix()` checks each row for palindrome symmetry.
* The result is printed to indicate whether the matrix satisfies the condition.

### ✅ Sample Output

```
|  1   2   1  |
|  5   6   5  |
|  7   8   7  |
Matrix is Palindrome Matrix

|  6   2   1  |
|  5   6   5  |
|  7   8   7  |
Matrix is Not Palindrome Matrix
```
