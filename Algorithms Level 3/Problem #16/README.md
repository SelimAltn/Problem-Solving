## 🧮 Sparse Matrix Check

### 💡 Problem Description

This program determines whether a given 3x3 matrix is *sparse*. A sparse matrix is one in which the number of zero elements is greater than the number of non-zero elements.

### 📌 Program Behavior

* Two 3x3 matrices are initialized.
* The first matrix is checked using a traditional loop-based method.
* The second matrix is checked using a faster approach by counting zero values.
* Results are printed to indicate whether each matrix is sparse.

### ✅ Example Output

```
Matrix 1 : 
| 10  0 12  |
| 20 15  1  |
|  0  0  9  |
No It Is Not Sparce 

Matrix 2 : 
|  0  0 12  |
|  0  0  1  |
|  0  0  9  |
Yes It Is sparce 
```
