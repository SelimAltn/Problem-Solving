### 💡 Problem Description

This program demonstrates how to manually remove leading and trailing spaces from a string without using built-in trimming functions. It includes three key functions:

* `TrimLeft`: Removes spaces from the beginning of the string.
* `TrimRight`: Removes spaces from the end of the string.
* `Trim`: Removes spaces from both sides using the previous two functions.

The user can see how each trimming operation affects the string.

---

### 📌 Program Behavior

* Accepts a hardcoded string with leading and trailing spaces.
* Applies `TrimLeft`, `TrimRight`, and `Trim` functions.
* Prints the results in a clear, visual format.

---

### ✅ Sample Output

```
[        Selim Altin       ]
Trim Left  : [Selim Altin       ]
Trim Right : [        Selim Altin]
Trim       : [Selim Altin]
```

---

### 🎯 Purpose

This problem helps understand how string manipulation works in C++ using loops and `substr()`, and how to implement basic trimming manually.
