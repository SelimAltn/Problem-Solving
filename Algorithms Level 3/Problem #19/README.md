## 🔢 Find Minimum and Maximum Number in a Matrix

### 💡 Problem Description

This program finds the **minimum** and **maximum** values in a 3x3 matrix filled with random numbers ranging from -30 to 30.

### 📌 Program Behavior

* A 3x3 matrix is filled with random integers between -30 and 30.
* It scans through the matrix to determine:

  * The smallest (minimum) number.
  * The largest (maximum) number.
* Results are printed after the matrix.

### ✅ Example Output

```
Matrix 1 : 
| -5   7  10  |
|  3 -30  22  |
|  0   9   8  |

Min Number is : -30
Max Number is : 22
```

### 🎯 Purpose

To practice:

* Searching for extreme values in 2D arrays.
* Using comparison logic inside nested loops.
* Working with signed random numbers.
