
### 💡 Problem Definition

This program generates two random 3x3 matrices and performs the following operations:

* Prints both matrices.
* Checks if both matrices are **identical** (element-by-element).
* Compares the **sum of all elements** in both matrices to determine if they are **sum-equal**.

---

### 📌 Program Workflow

1. `FillMatrixWithRandomNumbers`: Fills matrices with random values between 1 and 9.
2. `PrintMatrix`: Displays a formatted matrix.
3. `AreTypicalMatrices`: Compares both matrices element-by-element.
4. `SumAllNumerInMatrix`: Calculates the total sum of elements in a matrix.
5. `AreMatricesSumEqual`: Compares the sums of two matrices.

---

### ✅ Sample Output

```
Matrix 1 : 
| 03  04  01  |
| 02  07  09  |
| 05  01  06  |

Matrix 2 :

| 06  04  07  |
| 08  01  02  |

No Matrices Are Not Equal
Yes matrices sum are Equal
```
