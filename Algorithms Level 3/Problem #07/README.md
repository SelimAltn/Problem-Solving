### 💡 Problem Description

This program generates a 3x3 matrix filled with ordered numbers and calculates its transpose.

---

### 📌 Program Flow

1. A 3x3 matrix is filled with sequential numbers from 1 to 9.
2. The transpose of the matrix is calculated by swapping rows and columns.
3. Both the original and the transposed matrices are displayed.

---

### ✅ Sample Output

```
The following is a 3x3 ordered matrix:

|   1     2     3   |
|   4     5     6   |
|   7     8     9   |

The following is the Transpows matrix:

|   1     4     7   |
|   2     5     8   |
|   3     6     9   |
```

---

### 🎯 Goal

Practice how to transpose a square matrix and reinforce the concept of row-column swapping.
