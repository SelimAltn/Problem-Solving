## 🧮 Check if a Matrix is a Scalar Matrix

### 💡 Problem Description

This program checks whether a given 3x3 matrix is a **scalar matrix**.

A scalar matrix is a square matrix in which:

* All off-diagonal elements are **zero**.
* All diagonal elements are **equal to the same scalar value**.

### 📌 Program Behavior

* A 3x3 matrix is printed to the console.
* The program determines whether the matrix is scalar.
* It then outputs a corresponding message:
  **"YES: Matrix is Scalar."** or **"No: Matrix is NOT Scalar."**

### ✅ Example Output

```
| 09  00  00  |
| 00  09  00  |
| 00  00  09  |

YES: Matrix is Scalar.
```

### 🎯 Purpose

To practice matrix iteration, conditional logic, and recognition of special matrix types (like scalar matrices).
