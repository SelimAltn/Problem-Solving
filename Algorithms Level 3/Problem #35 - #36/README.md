# 🧩 Split and Count Words in a String

## 💡 Problem Description

This program reads a full line of text from the user and performs two main tasks:

1. Splits the string into individual words and prints each one on a new line.
2. Counts how many words exist in the string and prints the total.

## 📌 Program Features

* Uses `getline()` to handle full-line string input.
* Separates words based on spaces.
* Ignores extra or trailing spaces.
* Implements two functions:

  * `PrintEachWordInString(string)`: Displays each word separately.
  * `CountWords(string)`: Returns the number of words in the string.

## ✅ Example Output

```
Please Enter Your String ?
hello this is a test

hello
this
is
a
test

The number of words in your string is: 5
```

## 🎯 Purpose

This problem demonstrates basic string parsing, including how to split strings by delimiters and count the resulting components — an essential skill for text processing.
