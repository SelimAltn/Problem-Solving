
## 🔁 String Case Conversions: Uppercase, Lowercase, and Inversion

This program allows the user to perform three key operations on strings and characters:

* Convert an entire string to **uppercase**.
* Convert an entire string to **lowercase**.
* Invert the case of each letter in a string or a single character (i.e., uppercase becomes lowercase and vice versa).

---

### 💡 Problem Description

The program demonstrates various case conversion techniques:

1. Convert the entire string to **UPPERCASE**.
2. Convert the entire string to **lowercase**.
3. Invert the case of a **single character**.
4. Invert the case of **all characters** in a string.

These operations are performed using character-by-character iteration and standard `toupper` / `tolower` functions.

---

### 📌 How the Program Works

* A fixed string is used for uppercase and lowercase transformations.
* A character is read from the user and its case is inverted.
* Another string is read from the user and all its characters’ cases are inverted.
