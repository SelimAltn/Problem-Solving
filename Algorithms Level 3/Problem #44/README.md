### 💡 Problem Description

This program removes all punctuation characters from a given string using a manual loop and the `ispunct()` function.

---

### 📌 Program Behavior

* Takes a hardcoded sentence containing punctuation.
* Iterates through each character and skips any punctuation.
* Returns and prints the cleaned string.

---

### ✅ Sample Output

```
Welcome ! to Jordan , Jordan is a nice country.

Pauncuations Removed:
Welcome  to Jordan  Jordan is a nice country
```

---

### 🎯 Purpose

To demonstrate how to filter out punctuation characters using character-wise iteration and the `ispunct()` function in C++.
